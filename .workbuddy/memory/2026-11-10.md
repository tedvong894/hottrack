# 2026-11-10

## 从零搭建「热点追踪」App（短视频选题工作台）
- 需求：搜当天各平台热点 → 按政治/科技/社会等分类整理成案例 → 用于短视频涨粉，案例要有故事性和吸引力。
- 技术选型：**纯静态单页 + 独立数据文件**。`data.js` 用 `<script src>` 引入（不用 fetch），保证 `file://` 双击可用、无需服务器、无需 API key。以后更新只重写 `data.js`，`index.html` 不动。
- 文件：`index.html`（界面+全部逻辑）、`data.js`（每日案例库）、`manifest.json` + `icon-192/512.png` + `apple-touch-icon.png` + `favicon.ico`、`assets/make_icons.py`（Pillow 生成图标）。
- 已按「同域名多 App 铁律」配独立 manifest 与图标，`start_url`/`scope` 均为 `./`。
- UI：浅底黑字、低饱和、紧凑内联，符合用户一贯偏好；响应式适配手机。
- 功能：6 分类 tab、爆款分/分类/标题排序、搜索、收藏与「已拍」(localStorage)、一键复制完整 60 秒脚本或钩子、今日 TOP3 直达、风险提示、原始来源链接。
- **案例结构（核心设计）**：钩子 → 故事线「起承转合」→ 关键数字 → 3 个备选标题 → 封面文案 → 6 段分镜口播(约60秒) → 话题标签 → 涨粉点+评论区引导 → 「你的账号怎么切」(贴合用户「制造业外部军师」定位) → 风险提示 → 来源。
- 额外做了「今天别碰的热榜」避坑清单（重大伤亡、未决案件、未证实传闻、国际政治敏感等），比案例库更能防翻车。
- 合规口径：「政策·时政」分类只收官方公开发布的国内民生/经济政策，不做立场性解读；国际地缘、他国政坛、军事对峙一律放入避坑清单。

## Bug 修复（同日）
- **问题1：点开新闻/复制时卡片自动收起（像退回首页）**。根因：`#list` 的点击监听器里，卡片内任何非按钮点击都执行 `card.classList.toggle('open')`，导致展开后在详情区点击（定位光标、选中文字复制）就收起。修复：只有点 `.card-top` 头部才展开/收起；点在 `.detail` 详情区内部一律不收起。
- **问题2：每条新闻加删除按钮**。方案：客户端 localStorage 隐藏式删除（`state.deleted[id]=true`），不动 `data.js` 源；删后结果行出现「已隐藏 N 条，点此恢复」一键找回。删除按钮在卡片头部 `.flag` 区，带 confirm 防误删。
- 验证：本地起 http 服务 + Chrome DevTools Protocol 真机模拟——展开后点详情区仍保持展开、删除后卡片消失、恢复后 18 条全回。线上已部署（BUILD 20261110-1330），`index.html` 已含修复标记。
- 部署走 GitHub API（Git Data API），因 `gh`/git 直连被本地代理挡死；提交后 Actions 自动部署。
